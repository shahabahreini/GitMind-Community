# Cohere
> Verified against GitMind `6.0.0` on July 14, 2026.

Create a key in the [Cohere dashboard](https://dashboard.cohere.com/api-keys). The default is `command-a-plus-05-2026`; model discovery reflects account access. GitMind sends the selected diff and prompt to Cohere. Validate model access and account limits after authentication errors.
