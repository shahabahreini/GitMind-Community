# OpenAI
> Verified against GitMind `6.3.0` on September 27, 2026

Create a key on the [OpenAI API platform](https://platform.openai.com/api-keys). The default is `gpt-6-sol`; load models to see those available to the account. GitMind uses the Responses-compatible chat request shape for reasoning models and does not send unsupported temperature/top-p controls to them. Billing, project permissions, and rate limits are controlled by OpenAI.
