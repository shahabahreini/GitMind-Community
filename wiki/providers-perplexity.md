# Perplexity
> Verified against GitMind `6.1.1` on July 17, 2026

Create a key in [Perplexity settings](https://www.perplexity.ai/settings/api). The default is `sonar-pro`; GitMind offers a curated set of supported Sonar models instead of claiming live model discovery. GitMind sends the selected diff and prompt to Perplexity, and models may use online retrieval. Review the selected model's behavior and account quota.
