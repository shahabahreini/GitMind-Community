# xAI Grok
> Verified against GitMind `5.0.6` on July 13, 2026.

Create a key in the [xAI console](https://console.x.ai/). The default is `grok-4.4`; GitMind queries xAI's current `/models` catalog for account-visible choices. GitMind sends the selected diff and prompt to xAI. Check API access, selected model, and provider limits when setup fails.
