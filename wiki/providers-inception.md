# Inception Labs
> Verified against GitMind `6.6.0` on October 19, 2026

Create an API key on the [Inception Labs platform](https://platform.inceptionlabs.ai). The default model is `mercury-2.5`; **Load Available Models** refreshes the searchable catalog with active chat models from Inception Labs. GitMind sends the selected diff and prompt to Inception Labs over HTTPS with your API key. Confirm model availability and account limits after errors.
