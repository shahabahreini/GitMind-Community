# Ollama Cloud
> Verified against GitMind `6.6.0` on October 19, 2026

Create an API key in the [Ollama settings](https://ollama.com/settings/keys). The default model is `gpt-oss:120b-cloud`; **Load Available Models** refreshes the searchable catalog with active cloud-hosted models. GitMind sends the selected diff and prompt to Ollama Cloud over HTTPS with your API key. Confirm model availability and account limits after errors.
