# NVIDIA Hosted NIM
> Verified against GitMind `6.7.0` on October 27, 2026

Create a key at [NVIDIA Build](https://build.nvidia.com/models). The default is `nvidia/nemotron-3-super-120b-a12b`; **Load NVIDIA Models** refreshes hosted NIM discovery. GitMind sends the selected diff and prompt to NVIDIA's hosted API. Confirm the model is hosted and available to the key.
