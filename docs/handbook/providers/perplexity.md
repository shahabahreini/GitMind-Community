# Perplexity
> Verified against GitMind `6.1.2` on September 3, 2026

Create a key in [Perplexity settings](https://www.perplexity.ai/settings/api). The default is `sonar-pro`; GitMind uses Perplexity's Agent API (Sonar Chat Completions support ends September 27, 2026) and offers the documented Sonar models, because the Agent API has no model-list endpoint. GitMind sends the selected diff and prompt to Perplexity, and models may use online retrieval. Review the selected model's behavior and account quota.
