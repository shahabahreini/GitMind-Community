# Mistral AI
> Verified against GitMind `6.2.1` on September 22, 2026

Create an API key in the [Mistral console](https://console.mistral.ai/). The default is `mistral-small-2603`; **Load Mistral Models** refreshes the searchable catalog. GitMind sends the selected diff and prompt to Mistral. Check credentials, model access, and provider quota when requests fail.
