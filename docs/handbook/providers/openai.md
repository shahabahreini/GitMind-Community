# OpenAI
> Verified against GitMind `6.0.0` on July 14, 2026.

Create a key on the [OpenAI API platform](https://platform.openai.com/api-keys). The default is `gpt-5.6-terra`; load models to see those available to the account. GitMind uses the Responses-compatible chat request shape for reasoning models and does not send unsupported temperature/top-p controls to them. Billing, project permissions, and rate limits are controlled by OpenAI.
