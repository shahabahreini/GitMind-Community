# DeepSeek
> Verified against GitMind `6.2.0` on September 22, 2026

Create a key on the [DeepSeek platform](https://platform.deepseek.com/api_keys). The default is `deepseek-flash`; discovery shows available chat and reasoning models. GitMind sends the selected diff and prompt to DeepSeek. Check credentials, model access, and quota on failures.
